Materi pembelajaran

1. Sistem komputer

Sistem komputer merupakan kesatuan komponen yang bekerja bersama untuk menerima data, memprosesnya, menyimpan bila diperlukan, dan menghasilkan informasi atau tindakan. Komponen umumnya meliputi hardware (perangkat keras), software (perangkat lunak), dan brainware (manusia/pengguna).

Dalam sistem kendali: input → proses → output. Contoh: tombol (input), program mikrokontroler (proses), LED (output).

2. Single board controller dan mikrokontroler

Istilah single board controller biasa digunakan untuk papan pengendali elektronik yang mengintegrasikan mikrokontroler dan rangkaian pendukung pada satu papan. Arduino Uno adalah papan pengembangan berbasis mikrokontroler untuk belajar elektronika dan kendali.

Jangan menyamakan Arduino Uno dengan komputer umum. Single-board computer seperti Raspberry Pi umumnya menjalankan sistem operasi lengkap, sedangkan Arduino Uno menjalankan program mikrokontroler untuk mengendalikan perangkat.

3. Komponen dan pin Arduino Uno R3

  • ATmega328P: mikrokontroler utama pada Uno R3 standar.
  • Pin digital 0–13: membaca atau mengeluarkan sinyal digital; pin 0 dan 1 juga terkait komunikasi serial.
  • Pin analog A0–A5: membaca tegangan analog melalui ADC.
  • Pin PWM bertanda ~: menghasilkan sinyal PWM pada pin yang didukung.
  • 5V, 3.3V, GND, VIN: pin catu daya dan referensi ground sesuai kebutuhan rangkaian.
  • USB: menghubungkan papan ke komputer untuk pemrograman dan komunikasi.
  • Jack DC, reset, osilator, LED daya: membantu catu daya, memulai ulang, timing, dan indikasi daya.

LED bawaan pada Uno R3 standar terhubung ke pin digital 13. Detail dapat berbeda pada varian papan lain.

4. Struktur program Arduino

setup() dijalankan sekali saat program mulai atau papan di-reset. loop() dijalankan berulang kali. pinMode() mengatur fungsi pin, digitalWrite() mengatur keluaran digital, digitalRead() membaca input digital, dan delay() memberi jeda dalam milidetik.

const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}

Program menyalakan LED selama 1.000 ms (1 detik), mematikannya selama 1 detik, lalu mengulang proses tersebut.

Proyek mini: Lampu indikator Arduino

Tujuan

Membuat LED berkedip sebagai indikator status dengan memahami rangkaian, kode, dan pengujian.

Alat dan bahan

  • Arduino Uno dan kabel USB.
  • Breadboard dan kabel jumper.
  • LED, resistor pembatas arus yang sesuai (misalnya 220–330 Ω), dan komputer dengan Arduino IDE.

Langkah kerja

  1. Pastikan papan tidak terhubung ke sumber daya saat merakit rangkaian eksternal.
  2. Pasang LED eksternal secara seri dengan resistor; perhatikan polaritas LED.
  3. Hubungkan rangkaian ke pin digital yang dipilih dan GND.
  4. Tulis program untuk mengatur pin sebagai OUTPUT dan mengubah keadaan HIGH/LOW.
  5. Periksa sambungan, unggah program, lalu amati hasilnya.
  6. Catat hasil pengamatan dan jelaskan penyebab jika LED tidak menyala.

Contoh kode LED eksternal pada pin 8

const int ledPin = 8;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}

Rubrik penilaian

Ketepatan rangkaian — 30%

Pin, GND, polaritas, dan resistor terpasang benar.

Program — 30%

Program benar dan sesuai tujuan.

Pengujian — 20%

Melakukan uji dan mencatat hasil.

Analisis — 20%

Menjelaskan cara kerja dan perbaikan.
